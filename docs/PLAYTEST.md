# First playtest checklist (milestone 1)

Playtest link: https://jon8778-source.github.io/festival-manager/ (once GitHub Pages is switched on: repository Settings → Pages → Source: GitHub Actions).

## Before you start
- Open the link in Chrome on the phone or tablet, in portrait. Add to Home screen for a full-screen view.
- Use a normal (not private) tab, so the save and the log are kept.

## Play (about 12 minutes)
1. **New game.** Read Randy's first few lines, then decide whether to keep him or skip him.
2. **Book three bands** from the lineup: a headliner, a support act and an opener. Try at least one offer that's too low, to see a counter-offer or a rejection.
3. **Build the site:** toilets and food stalls. Watch the forecast change as you add them.
4. **Set a ticket price**, and watch the forecast attendance and profit move.
5. **Continue** through preparation. Answer the sound limiter email, and the slow-sales email if it comes.
6. **Festival day:** open the gates, answer each decision, and try the 2x button.
7. **Read the review.** Then tap **Replay** and play a second time, trying to get more stars.

## Things to check
- [ ] Every screen fits the width with no sideways scrolling, and buttons are easy to tap.
- [ ] Close the browser halfway through preparation, reopen the link, and tap **Continue planning**. You should be back where you were.
- [ ] Close it during the festival day and reopen. You should resume at the gates.
- [ ] Settings → **Export save** gives a file. **Import save** loads it again.
- [ ] Settings → **Download log** gives a .jsonl file. Send this to the developer.

## Questions to note down afterwards
- Was it clear what to do first? Where did you get stuck?
- Did the negotiation feel fair? Did the counter-offers make sense?
- Did the forecast help you plan? Did the result match what you expected?
- How many stars did you get on each attempt, and how long did a run take?
- Was Randy helpful, too chatty, or about right?
- Anything that looked broken, confusing or wrong?
